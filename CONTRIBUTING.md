# Guía de Contribución

¡Gracias por tu interés en contribuir a ProVacuno! 🎉

## 📋 Cómo Contribuir

### Reportando Issues

Este repositorio está dedicado principalmente al seguimiento de issues para la aplicación móvil ProVacuno. Puedes contribuir de las siguientes maneras:

#### 🐛 Reportar Bugs

1. **Busca primero**: Verifica si el bug ya ha sido reportado
2. **Usa la plantilla**: Utiliza la plantilla de "Bug Report"
3. **Sé específico**: Incluye toda la información solicitada en la plantilla
4. **Adjunta evidencia**: Capturas de pantalla, logs, etc.

#### ✨ Sugerir Funcionalidades

1. **Verifica que no exista**: Revisa los issues existentes
2. **Usa la plantilla**: Utiliza la plantilla de "Feature Request"
3. **Explica el valor**: Describe por qué esta funcionalidad sería útil
4. **Proporciona ejemplos**: Mockups, referencias de otras apps, etc.

#### ❓ Hacer Preguntas

1. **Busca primero**: Puede que tu pregunta ya haya sido respondida
2. **Usa la plantilla**: Utiliza la plantilla de "Pregunta o Soporte"
3. **Proporciona contexto**: Explica tu situación claramente

### Buenas Prácticas

- ✅ **Sé respetuoso**: Trata a todos con respeto y profesionalismo
- ✅ **Sé claro**: Usa un lenguaje claro y conciso
- ✅ **Sé paciente**: El equipo revisará tu issue cuando sea posible
- ✅ **Mantén el foco**: Un issue por problema o sugerencia
- ✅ **Actualiza**: Si encuentras más información o una solución, actualiza el issue

### Qué NO hacer

- ❌ No uses este repositorio para promocionar productos o servicios
- ❌ No publiques información sensible o personal
- ❌ No abras issues duplicados
- ❌ No uses lenguaje ofensivo o inapropiado
- ❌ No hagas spam

## 🏷️ Etiquetas (Labels)

Los issues serán etiquetados para facilitar su seguimiento:

- `bug` - Errores o comportamientos inesperados
- `enhancement` - Nuevas funcionalidades o mejoras
- `question` - Preguntas y consultas
- `documentation` - Relacionado con documentación
- `duplicate` - Issue duplicado
- `wontfix` - No se implementará o arreglará
- `help wanted` - Se busca ayuda de la comunidad

## 📞 Contacto

Para consultas que no sean apropiadas para un issue público, contacta al equipo de ProVacuno a través de los canales oficiales.

## 🙏 Agradecimientos

Gracias por ayudar a mejorar ProVacuno. Tu feedback es valioso y ayuda a hacer de esta una mejor aplicación para todos.
