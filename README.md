# ProVacuno - Canal de Soporte y Feedback 🐄

Bienvenido al repositorio oficial de soporte y feedback para **ProVacuno**, una aplicación móvil híbrida desarrollada con Ionic.

## 📱 Acerca de ProVacuno

ProVacuno es una aplicación móvil diseñada para proporcionar información y servicios relacionados con el sector vacuno. Esta aplicación híbrida, construida con el framework Ionic, ofrece una experiencia multiplataforma para dispositivos iOS y Android.

## 🎯 Propósito de este Repositorio

Este repositorio sirve como **canal oficial de soporte** para:

- 🐛 **Reportar bugs y errores** encontrados en la aplicación
- 💡 **Sugerir nuevas características** y mejoras
- ❓ **Realizar consultas** sobre el funcionamiento de la aplicación
- 📝 **Proporcionar feedback** general sobre la experiencia de usuario
- 🔧 **Solicitar soporte técnico** para problemas específicos

## 📋 Cómo Reportar un Issue

Para reportar un problema, sugerencia o consulta:

1. **Busca primero**: Verifica si ya existe un issue similar antes de crear uno nuevo
2. **Usa las plantillas**: Selecciona la plantilla apropiada al crear un nuevo issue:
   - 🐛 Bug Report - Para reportar errores o fallos
   - ✨ Feature Request - Para sugerir nuevas funcionalidades
   - ❓ Pregunta/Soporte - Para consultas generales
3. **Proporciona detalles**: Cuanta más información proporciones, más rápido podremos ayudarte
4. **Sé respetuoso**: Mantén un tono profesional y constructivo
